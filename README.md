# iptvys

定制影视播放器。支持rtp2httpd代理的rtsp源。支持rtsp节目时长信息获取，进度条拖动，快进快退等。


###  基于蜂蜜影视版：
TV版：leanback-arm64_v8a.apk leanback-armeabi_v7a.apk<br>
手机版：mobile-arm64_v8a.apk mobile-armeabi_v7a.apk

### 基于OK影视版：
TV版： leanback-java-arm64_v8a.apk leanback-java-armeabi_v7a.apk<br>
手机版: mobile-java-arm64_v8a.apk mobile-java-armeabi_v7a.apk
